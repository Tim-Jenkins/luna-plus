# luna-plus

Passion project to get the LUNA Online MMORPG (C++/DirectX 9 client, Map/Agent/Distribute servers, engine and tools) building and running on modern systems.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for Tim-Jenkins/luna-plus via the `gh` CLI; external PRs are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
